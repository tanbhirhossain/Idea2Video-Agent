Administration

AI services

Set the Ollama script API and model, plus the ComfyUI visual-generation server. These settings are saved to the local project configuration.

Script generation · Ollama

Use a local or reachable Ollama server. The selected model must be installed there.

Higher limits help long, many-scene scripts avoid truncated JSON. The generator retries once with a larger limit if Ollama stops at its token cap.

If the model returns empty or invalid JSON, the generator already retries once with thinking enabled.

Visual generation · ComfyUI

Higher megapixels can improve detail but use more GPU memory; generation automatically falls back to a lower resolution on memory errors.

This build uses Ollama and ComfyUI. It does not store third-party API keys or configure OpenAI-compatible providers; the endpoint fields above point to the services this project already supports.
